Fetching and Displaying Currency Exchange Rate Details Using API

To fetch currency exchange rate information from an online API and display required details such as base currency, selected currency, exchange rate, last updated time, and API status.

💻 Code

import requests

response = requests.get("https://open.er-api.com/v6/latest/USD")
data = response.json()

target_currency = input("Enter Target currency : ")

base_currency = data["base_code"]

exchange_rate = data["rates"][target_currency]
print("Base Currency : ", base_currency)
print("Target Currency : ", target_currency)
print("Exchange Rate : ",exchange_rate )

Fetching Product Data and Downloading Thumbnail Images

ETo fetch product details from an API, extract thumbnail image URLs, and download images using product names as filenames.

💻 Code

import requests

response = requests.get("https://dummyjson.com/products")

data = response.json()

for item in data["products"] :
    thumbnail = item["thumbnail"]
    url = requests.get(thumbnail)
    fn = item["title"] + ".webp"
    # print(fn," , ",thumbnail)
    with open(fn,"wb") as f:
        f.write(url.content)
        f.close()

Downloading Images According to Specific Conditions

To fetch image data from an API and download only those images that satisfy given conditions.

💻 Code

import requests
import os

folder = "small images"
os.makedirs(folder, exist_ok=True)

response = requests.get("https://api.imgflip.com/get_memes")

data = response.json()

for info in data["data"]["memes"]:
    if info["width"] < 400 :
        img = info["url"]
        r = requests.get(img)
        fn = info["id"] + ".jpg"
        file_path = os.path.join(folder,fn)
        with open(file_path,"wb") as f :
            f.write(r.content)
            f.close()

Extracting Pokémon Details and Downloading Images Based on Weight

To retrieve Pokémon information from an API, extract details, and download images of Pokémon satisfying a specific weight condition.

💻 Code

import requests

response = requests.get("https://pokeapi.co/api/v2/pokemon?limit=1000&offset=0")
data = response.json()
print("pokemons with weight less than 80 kg are : ")
for item in data["results"]:
    url = item["url"]
    name = item["name"]
    dino_info = requests.get(url)
    dino_data = dino_info.json()
    # print(dino_data["weight"])
    if dino_data["weight"] < 80 :
        print(name,url)
        img = requests.get(dino_data["sprites"]["front_default"])
        fn = name + ".png"
        with open(fn,"wb") as f :
            f.write(img.content)
            f.close()
