Activity 1: Categorical Programming Language Popularity Pie Charts

Construct pie charts displaying programming language popularity, customize formatting options, and apply multi-wedge explosions to highlight specific data segments.

Tasks Performed

  • Define proportional numeric datasets and corresponding qualitative category labels
  • Render pie charts displaying formatted floating-point percentages up to two decimal places
  • Apply depth elevation shadows (shadow=True) and standalone figure titles
  • Configure single-wedge and multi-wedge offset arrays (explode) to visually emphasize key segments

Code

import matplotlib.pyplot as plt

# Dataset: Programming Language Popularity
popularity = [22.2, 17.6, 8.8, 8, 7.7, 6.7]
pl = ['Java', 'Python', 'PHP', 'JavaScript', 'C#', 'C++']

# 1. Basic Pie Chart with Single Wedge Explode & Shadows
plt.figure()
plt.pie(x=popularity, labels=pl, autopct='%1.2f%%', shadow=True, explode=[0.1, 0, 0, 0, 0, 0])
plt.title("Popularity of Programming Languages (Single Explode)")
plt.show()

# 2. Pie Chart with Title and Multi-Wedge Explodes
plt.figure()
plt.pie(x=popularity, labels=pl, autopct='%1.2f%%', shadow=True, explode=[0.1, 0, 0, 0, 0, 0.1])
plt.title("Popularity of Programming Languages (Multi Explode)")
plt.show()

Activity 2: Dynamic Pie Chart Generation from External CSV Data

Extract gold medal counts from an external Olympic dataset (medal.csv) using Pandas and plot a dynamic, percentage-labeled pie chart.

Tasks Performed

  • Load 2016 Summer Olympics gold medal data (medal.csv) into a Pandas DataFrame
  • Extract country names and medal tallies into list structures using zip() iteration
  • Render a customized pie chart displaying gold medal shares across top performing nations
  • Highlight the leading nation's sector by applying a focal offset (explode = [0.1, 0, 0, 0, 0])

Code

import pandas as pd
import matplotlib.pyplot as plt

# Load Olympic Medal Dataset
data = pd.read_csv("medal.csv")

countries = []
gold_medals = []

# Extract data using zip iteration
for c, g in zip(data["country"], data["gold_medal"]):
    countries.append(c)
    gold_medals.append(g)

# Render Olympic Gold Medal Distribution Pie Chart
plt.figure()
plt.pie(x=gold_medals, labels=countries, autopct='%1.2f%%', shadow=True, explode=[0.1, 0, 0, 0, 0])
plt.title("2016 Summer Olympics - Top 5 Gold Medal Distribution")
plt.show()

Key Learnings

  • Using Matplotlib's plt.pie() function to illustrate proportional distributions
  • Formatting numeric sector labels automatically using string format specifiers like autopct='%1.2f%%'
  • Enhancing visual hierarchy using the explode parameter to offset specific pie slices from the center
  • Adding visual depth using shadow=True to make pie charts pop off the canvas
  • Iterating over Pandas DataFrame columns using zip() to build dynamic input vectors for Matplotlib charts
