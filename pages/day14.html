Activity 1: Comparative Continuous Regression Analysis (Insurance Charges Dataset)

Process numerical predictors from customer demographic data, shuffle observations, partition training-testing sets, and evaluate performance across multiple regression algorithms.

Tasks Performed

  • Separate target output labels (charges) from predictor attributes
  • Perform random row index permutations to avoid data ordering bias
  • Fit Decision Tree, Support Vector, and Random Forest Regressors
  • Compute error distributions (MAE, MSE, RMSE) and variance metrics ($R^2$) across all models

Code

import pandas as pd
import numpy as np
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score
from sklearn.tree import DecisionTreeRegressor
from sklearn.svm import SVR
from sklearn.ensemble import RandomForestRegressor

# Load dataset
data = "insurance.csv"
df = pd.read_csv(data)

# Preprocessing: Isolate numeric predictors and target variable
x = df.drop(columns={"charges", "sex", "smoker", "region"})
y = df["charges"]

# Randomly shuffle dataset indices
indices = np.random.permutation(len(df))
x = x.iloc[indices]
y = y.iloc[indices]

# Partition into 80% training and 20% testing splits
split_index = int(len(df) * 0.80)
x_train = x.iloc[:split_index]
y_train = y.iloc[:split_index]
x_test = x.iloc[split_index:]
y_test = y.iloc[split_index:]

# 1. Decision Tree Regressor
dtr = DecisionTreeRegressor().fit(x_train, y_train)
prediction = dtr.predict(x_test)
mae = mean_absolute_error(y_test, prediction)
mse = mean_squared_error(y_test, prediction)
rmse = np.sqrt(mse)
r2 = r2_score(y_test, prediction)

print("--- Decision Tree Regressor ---")
print("Mean Absolute Error     :", mae)
print("Mean Squared Error      :", mse)
print("Root Mean Squared Error :", rmse)
print("R2 Score                :", r2)

# 2. Support Vector Regressor
svr = SVR().fit(x_train, y_train)
prediction = svr.predict(x_test)
mae = mean_absolute_error(y_test, prediction)
mse = mean_squared_error(y_test, prediction)
rmse = np.sqrt(mse)
r2 = r2_score(y_test, prediction)

print("\n--- Support Vector Regressor ---")
print("Mean Absolute Error     :", mae)
print("Mean Squared Error      :", mse)
print("Root Mean Squared Error :", rmse)
print("R2 Score                :", r2)

# 3. Random Forest Regressor
rfr = RandomForestRegressor().fit(x_train, y_train)
prediction = rfr.predict(x_test)
mae = mean_absolute_error(y_test, prediction)
mse = mean_squared_error(y_test, prediction)
rmse = np.sqrt(mse)
r2 = r2_score(y_test, prediction)

print("\n--- Random Forest Regressor ---")
print("Mean Absolute Error     :", mae)
print("Mean Squared Error      :", mse)
print("Root Mean Squared Error :", rmse)
print("R2 Score                :", r2)

Activity 2: Diagnostic Support Vector Classification & Metric Evaluation (Heart Disease Dataset)

Build a Support Vector Classifier (SVC) pipeline on heart disease diagnostic features and evaluate performance using comprehensive classification metrics.

Tasks Performed

  • Partition diagnostic features and target labels using Scikit-Learn's train_test_split
  • Set explicit seed values (random_state=30) to ensure consistent test results
  • Train a Support Vector Classifier (SVC) on clinical training data
  • Calculate and analyze Accuracy, Precision, Recall, and $F_1$-score on test predictions

Code

import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn import svm
from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score

# Load diagnostic dataset
data = pd.read_csv("heart.csv")

# Separate features and target binary variable
x = data.drop(columns="target")
y = data["target"]

# Partition into 80:20 train-test split using reproducible seed state
x_train, x_test, y_train, y_test = train_test_split(x, y, test_size=0.20, random_state=30)

# Initialize and train Support Vector Classifier
model = svm.SVC()
model.fit(x_train, y_train)

# Predict target labels for testing subset
prediction = model.predict(x_test)

# Calculate diagnostic evaluation metrics
print("--- Support Vector Classifier Performance ---")
print("Accuracy  : ", accuracy_score(y_test, prediction))
print("Precision : ", precision_score(y_test, prediction))
print("Recall    : ", recall_score(y_test, prediction))
print("F1 Score  : ", f1_score(y_test, prediction))

Key Learnings

  • Observing performance variations between single decision trees, support vector regressors, and ensemble random forest models
  • Using Scikit-Learn's train_test_split function with fixed random_state values for reliable experimental setups
  • Evaluating binary classification models using Precision, Recall, and $F_1$-score alongside standard accuracy
  • Recognizing the importance of recall and precision in medical diagnostic applications where false negatives carry significant risks
