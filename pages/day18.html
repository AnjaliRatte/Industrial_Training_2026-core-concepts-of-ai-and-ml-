Activity 1: Dataset Auditing, Skewness Analysis & Missing Value Imputation

Load the tab-separated dataset, calculate missing value distributions, analyze attribute skewness to determine the imputation strategy, and visualize income data using Matplotlib.

Tasks Performed

  • Import tab-delimited dataset (marketing_campaign.csv) and inspect structural dimensions
  • Identify missing value counts and evaluate skewness on continuous variables (Income)
  • Impute missing numerical values using median imputation due to high positive skewness ($6.76$)
  • Plot distribution charts using Matplotlib line plots to visualize income spread across dataset indices

Code

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# Load tab-delimited marketing campaign dataset
df = pd.read_csv("marketing_campaign.csv", delimiter="\t")

# Structural Inspection
print("Dataset Shape :", df.shape)
print("Missing Values per Column:\n", df.isnull().sum())

# Skewness Analysis for Imputation Strategy
print("Income Mean   :", df["Income"].mean())
print("Income Median :", df["Income"].median())
print("Income Skew   :", df["Income"].skew())  # Skew > 1 indicates highly skewed data

# Visualize Income Distribution
plt.figure(figsize=(10, 5))
plt.plot(df["Income"].dropna())
plt.xlabel("Data Points (Rows)")
plt.ylabel("Income")
plt.title("Income Line Graph")
plt.show()

# Impute missing values using median due to high skewness
df["Income"] = df["Income"].fillna(df["Income"].median())

Activity 2: Data Quality Auditing, Feature Engineering & Label Encoding

Audit dataset entries for invalid records, engineer an age-group demographic feature from birth years, apply label encoding across qualitative categories, and split predictor features from targets.

Tasks Performed

  • Audit numerical boundaries to check for invalid records such as negative income or future birth years
  • Engineer custom categorical feature (age_group) using birth year transformations
  • Encode categorical variables into discrete numeric integers using Scikit-Learn's LabelEncoder
  • Separate predictor feature matrix ($X$) from binary campaign response labels ($y$) and export cleaned output

Code

from sklearn.preprocessing import LabelEncoder, OneHotEncoder

# Data Quality Check: Inspect invalid ages or negative income
invalid_birth_years = df[df["Year_Birth"] > 2026]
negative_incomes = df[df["Income"] < 0]

# Feature Engineering: Calculate age and categorize into age groups
def calculate_age(year):
    return int(2026 - year)

def get_age_group(year):
    age = calculate_age(year)
    if age < 18:
        return "Child"
    elif age < 30:
        return "Young Adult"
    elif age < 50:
        return "Adult"
    else:
        return "Senior"

# Apply age grouping transformation
df["Year_Birth"] = df["Year_Birth"].astype(int)
df["age_group"] = df["Year_Birth"].apply(get_age_group)

# Categorical Encoding using LabelEncoder
le = LabelEncoder()
categorical_columns = df.select_dtypes(include=["object", "string"]).columns

for column in categorical_columns:
    df[column] = le.fit_transform(df[column])

# Separate Features (X) and Target Label (y)
X = df.drop(columns={"Response"})
y = df["Response"]

print("\nFeatures (X) Shape:", X.shape)
print("Target (y) Shape  :", y.shape)

# Export processed dataset
df.to_csv("customer_processed.csv", index=False)
print("Processed dataset saved successfully as 'customer_processed.csv'.")
