Activity 1: File I/O Line Plotting & Financial Time-Series Visualization

Extract coordinate data directly from external text files and plot financial stock prices across multiple attributes using Pandas data structure integration.

Tasks Performed

  • Parse space-delimited text records (test.txt) to construct dynamic feature vectors
  • Load Alphabet Inc. stock market records (fdata.csv) using Pandas DataFrames
  • Plot multi-variable stock metrics (Open, High, Low, Close) on shared time-series axes with automated legends
  • Apply grid overlays and custom marker parameters to highlight data inflection points

Code

import matplotlib.pyplot as plt
import pandas as pd

# Task 3: Read Line Plot Data from Text File
x_file, y_file = [], []

with open("test.txt", 'r') as file:
    for line in file:
        a, b = map(int, line.split())
        x_file.append(a)
        y_file.append(b)

plt.figure()
plt.plot(x_file, y_file, color='yellow', marker='o', markerfacecolor='red', markeredgecolor='green', linewidth=1)
plt.xlabel("X Axis")
plt.ylabel("Y Axis")
plt.title("Data Read from Text File")
plt.grid(True)
plt.show()

# Task 4: Plot Financial Market Time-Series Data
df = pd.read_csv("fdata.csv", delimiter=',')

dates = df["Date"]
plt.figure()
plt.plot(dates, df["Open"], label="Open")
plt.plot(dates, df["Low"], label="Low")
plt.plot(dates, df["High"], label="High")
plt.plot(dates, df["Close"], label="Close")

plt.xlabel("Dates")
plt.ylabel("Price")
plt.title("Financial Data of Alphabet Inc.")
plt.legend()
plt.grid(True)
plt.show()

Activity 2: Multi-Line Plotting, Trigonometric Functions & Axis Boundary Manipulation

Render multi-series mathematical curves on unified canvas figures, customize line dash styles, apply distinct point markers, and control plot boundary limits.

Tasks Performed

  • Generate continuous numerical domains using NumPy's linspace
  • Plot trigonometric functions ($\sin$, $\cos$, $\tan$) with distinctive colors, line widths, and dash styles (linestyle='--', ':')
  • Customize point marker geometries ('o', ',', 'v') along with face and edge color fills
  • Inspect default axis bounding limits and override them dynamically using plt.axis([xmin, xmax, ymin, ymax])

Code

import matplotlib.pyplot as plt
import numpy as np

# Task 5, 6 & 7: Multi-Line Mathematical Plotting with Styles
x = np.linspace(0, 2 * np.pi, 100)

plt.figure()
plt.plot(x, np.sin(x), label="sin(x)", color='red', linewidth=2, linestyle=':')
plt.plot(x, np.cos(x), label="cos(x)", color='cyan', linewidth=4, linestyle='--')
plt.title("Trigonometric Curves with Custom Styles")
plt.xlabel("Radians")
plt.ylabel("Magnitude")
plt.legend()
plt.grid(True)
plt.show()

# Task 8: Setting Line Markers across Multiple Curves
x_vals = [i for i in range(0, 20)]
y1 = [j for j in range(0, 40, 2)]
y2 = [k for k in range(0, 60, 3)]
y3 = [l for l in range(0, 80, 4)]

plt.figure()
plt.plot(x_vals, y1, marker='o', markerfacecolor='yellow', markeredgecolor='red', linestyle='--')
plt.plot(x_vals, y2, marker=',', markerfacecolor='cyan', markeredgecolor='green', linestyle=':')
plt.plot(x_vals, y3, marker='v', markerfacecolor='orange', markeredgecolor='brown', linestyle='-')
plt.title("Custom Line Markers")
plt.show()

# Task 9: Display and Modify Axis Limits
x_pts = [1, 2, 3, 4, 5]
y_pts = [4, 2, 3, 1, 5]

plt.figure()
plt.plot(x_pts, y_pts)
print("Current Default Axis Limits:", plt.axis())

# Apply modified axis boundaries
plt.axis([0, 7, 0, 7])
plt.title("Plot with Custom Axis Limits [0, 7, 0, 7]")
plt.show()
