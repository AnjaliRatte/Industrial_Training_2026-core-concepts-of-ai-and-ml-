Activity 2 : Display Book Cover

The cover_i value obtained from the Open Library API was used as the unique identifier to construct the book cover URL. By appending this value to the Open Library Covers API URL format, the corresponding book cover image was successfully retrieved and displayed.

Code


import requests
import os

response = requests.get("https://openlibrary.org/search.json?title=python")

data = response.json()

result = []
for info in data["docs"]:
    row = [
        info["title"]
    ]
    if "cover_i" in info :
        cover_i = str(info["cover_i"])
        url = "https://covers.openlibrary.org/b/id/" + cover_i + "-L.jpg"
        row.append(url)
        result.append(row)
    else :
        row.append("null")


print(result)

folder = "book covers"
os.makedirs(folder, exist_ok=True)

for book in result :
    title = book[0] + ".jpg"
    cover = book[1]
    co_url = requests.get(cover)
    file_path = os.path.join(folder, title)
    with open (file_path,"wb") as f:
        f.write(co_url.content)
        f.close()

Activity 3 : REST Countries API

Data was fetched from the REST Countries API using an HTTP GET request in Python. The JSON response received from the API was parsed to extract relevant details such as the country name, capital city, population, and area. The extracted information was then organized into a list of lists, where each inner list represented a country and contained its corresponding details. This structured format made the data easy to display, access, and process for further analysis.

Extracted Fields
Country Name
Capital
Population
Area

Code


import requests

# API call
response = requests.get(
    "https://api.restcountries.com/countries/v5?limit=100&pretty=1",
    headers={
        "Authorization": "Bearer rc_live_ead02b60371441b9888fbb28757ed6c2"
    }
)

data = response.json()

# result list
result = []

# loop through countries
for info in data["data"]["objects"]:

    # ---- Country Name ----
    country_name = info.get("names", {}).get("common", "N/A")

    # ---- Capital City ----
    capitals = info.get("capitals", [])
    if capitals:
        capital_name = capitals[0].get("name", "N/A")
    else:
        capital_name = "N/A"

    # ---- Population ----
    population = info.get("population", "N/A")

    # ---- Area ----
    area = info.get("area", {}).get("kilometers", "N/A")

    # ---- create row ----
    row = [country_name, capital_name, population, area]

    result.append(row)

# print result
for r in result:
    print(r)

Activity 4 : Countries with Population Greater Than 50 Million

The program filtered the country data by checking the population value of each country obtained from the REST Countries API. It iterated through the list of countries and used a conditional statement to compare each country's population with 50 million. If the population was greater than 50 million, the country's name was added to the result and displayed. This demonstrated the use of conditional filtering to extract specific information from a large dataset.

💻 Code


import requests

Activity 5 : Filter Countries by Region

The program takes the region name as input from the user. It filters the country data by comparing the entered region with the region field in the API data. When "Africa" is entered, only countries belonging to the Africa region are selected and displayed with their details.

Code


import requests

response = requests.get(
    "https://api.restcountries.com/countries/v5?limit=100&pretty=1",
    headers = {
        "Authorization" : "Bearer rc_live_ead02b60371441b9888fbb28757ed6c2"
    }
)

data = response.json()
# print(data)

regions = []

for info in data["data"]["objects"]:
    r_name = info.get("region")
    if r_name not in regions:
        regions.append(r_name)
# print(regions)

countries = {}
for region in regions :
    country = []
    for info in data["data"]["objects"]:
        if info.get("region") == region :
            country.append(info.get("names").get("common"))
    countries[region]= country

# print(countries)

reg = input("Enter any region ['Asia', 'Europe', 'Africa', 'Oceania', 'Americas', 'Antarctic'] :  ")
print("Countries in region " ,  reg, " are : ", countries[reg])
