I examined selected medical features to identify zero values that may represent missing or invalid measurements rather than actual observations.

🧹 Activity 3: Handling Invalid Zero Values

I replaced zero values in selected medical features with their respective median values. This helped prepare the dataset for further machine learning operations.

💻 Code

for col in columns:
    med = data[col].median()
    data[col] = data[col].replace(0, med)

# Verify replacement
for col in columns:
    print(col, (data[col] == 0).sum())

📊 Output

Verification of zero values
after median replacement

Median imputation was applied to the selected columns to reduce the effect of invalid zero values.

🔀 Activity 5: Training and Testing Split

I shuffled the dataset indices using NumPy to randomize the order of observations. I then split the dataset into 80% training data and 20% testing data to prepare for machine learning model training and evaluation.

💻 Code

import numpy as np

indices = np.random.permutation(len(data))

x = x.iloc[indices]
y = y.iloc[indices]

split_index = int(len(data) * 0.80)

x_train = x.iloc[:split_index]
y_train = y.iloc[:split_index]

x_test = x.iloc[split_index:]
y_test = y.iloc[split_index:]

# Check dataset shapes
print(x_train.shape, y_train.shape)
print(x_test.shape, y_test.shape)
