Day 16 - Categorical Dataset Exploration, Label Encoding & Data Cleaning

Industrial Training Diary

Introduction

On the sixteenth day of industrial training, I focused on end-to-end Exploratory Data Analysis (EDA) and data preprocessing for fully categorical datasets using the Mushroom Classification dataset. I performed structural exploration, missing value analysis, duplicate row checks, and label encoding using Scikit-Learn's LabelEncoder to convert qualitative string features into numeric formats. Finally, I structured the data by partitioning predictor features from target labels and exporting the preprocessed dataset.

Learning Objectives

  • Perform comprehensive initial EDA using Pandas (head, tail, shape, columns, and memory_usage)
  • Analyze missing value distributions (isna().sum()) and check record redundancy (duplicated())
  • Identify unique categories across categorical features using nunique() and unique()
  • Distinguish categorical datasets from numerical ones by inspecting column data types programmatically
  • Encode non-numeric categorical attributes using Scikit-Learn's LabelEncoder and save cleaned data to CSV

Activity 1: Dataset Loading, Structural Exploration & Health Checks

Load the Mushroom dataset into pandas, inspect structural dimensions, evaluate memory usage, and verify data integrity by checking missing values and duplicate rows.

Tasks Performed

  • Load raw dataset (mushrooms.csv) and display head/tail records and structural shape
  • Inspect data types, total column counts, and total memory footprint
  • Evaluate missing value counts across all features using isna().sum()
  • Detect and count potential duplicate observations across row indices
  • Analyze unique category distributions across all qualitative columns using loop iteration

Code

import pandas as pd

# Task 1: Load the Dataset
data = pd.read_csv("mushrooms.csv")

print("--- Initial Inspection ---")
print("First 5 Rows:\n", data.head())
print("Last 5 Rows:\n", data.tail())
print("Dataset Shape:", data.shape)
print("Number of Columns:", data.shape[1])

# Task 2 & 4: Dataset Exploration & Missing Value Analysis
print("\n--- Structural Properties ---")
print("Column Names:\n", data.columns)
print("Data Types:\n", data.dtypes)
print("Missing Values Per Column:\n", data.isna().sum())
print("Total Duplicate Rows:", data.duplicated().sum())
print("Memory Usage:\n", data.memory_usage())

# Task 6: Unique Values Inspection
print("\n--- Unique Categorical Values ---")
for column in data.columns:
    print(f"{column}: {data[column].unique()}")
print("\nUnique Value Counts Per Column:\n", data.nunique())

Activity 2: Categorical Feature Isolation, Label Encoding & Feature Splitting

Separate string/object features, transform qualitative categories into discrete numerical labels using LabelEncoder, isolate predictor features from target labels, and export the cleaned dataset.

Tasks Performed

  • Isolate categorical columns (object / string) programmatically from potential numeric features
  • Apply Scikit-Learn's LabelEncoder iteratively across all categorical columns
  • Separate target output labels (class) from predictor attributes (X)
  • Export the encoded, clean dataset as mushroom_cleaned.csv for model training

Code

from sklearn.preprocessing import LabelEncoder

# Task 8: Identify Categorical Features
categorical_columns = data.select_dtypes(include={"object", "string"})
numerical_columns = data.select_dtypes(include=["int64", "float64"])

print("Number of Categorical Columns:", categorical_columns.shape[1])
print("Number of Numerical Columns:", numerical_columns.shape[1])

# Task 9: Encode Categorical Features
le = LabelEncoder()
newdata = pd.DataFrame()

for column in categorical_columns.columns:
    newdata[column] = le.fit_transform(categorical_columns[column])

print("\n--- Post-Encoding Inspection ---")
print(newdata.head())
print(newdata.dtypes)

# Task 10: Separate Features and Target
X = newdata.drop(columns="class")
y = newdata["class"]

print("\nFeatures (X) Shape:", X.shape)
print("Target (y) Shape  :", y.shape)

# Task 11: Save Cleaned Dataset
newdata.to_csv("mushroom_cleaned.csv", index=False)
print("\nCleaned dataset saved successfully as 'mushroom_cleaned.csv'.")

Key Learnings

  • Understanding why non-numeric categorical attributes must be encoded before passing data into machine learning algorithms
  • Mastering LabelEncoder for converting categorical string labels into discrete integer representations
  • Identifying fully categorical datasets where every feature represents nominal qualitative states rather than continuous numeric measurements
  • Executing standard data hygiene practices including duplicate detection, missing value auditing, and column data type isolation
  • Exporting cleaned data pipelines using to_csv(index=False) to preserve processed state across machine learning workflows
