Activity 1: Wikipedia Page Scraping (Heading and Subheadings)

Fetch the Wikipedia page for the "Flag of India", extract the main page heading (<h1>), and list out all the subheadings (<h2>) present on the page.

Tasks Performed

  • Send a GET request to Wikipedia using custom headers to avoid bot detection
  • Extract the main title using soup.find("h1")
  • Extract all secondary sections using soup.find_all("h2") and print their text

Code

import requests
from bs4 import BeautifulSoup

url = "https://en.wikipedia.org/wiki/Flag_of_India"

headers = {'User-Agent': 'Mozilla/5.0 (Macintosh; Intel Mac OS X 10_11_5) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/50.0.2661.102 Safari/537.36'}
result = requests.get(url, headers=headers)
data = result.content

soup = BeautifulSoup(data, 'html.parser')

# Get main heading
heading = soup.find("h1")
print(heading.text)

# Get all subheadings
sh = soup.find_all("h2")
for h in sh:
    print(h.text)

Activity 2: Extracting Country Names from Worldometers

Scrape the Worldometers flags webpage to extract and print the names of all countries listed.

Tasks Performed

  • Fetch the webpage content from the given URL
  • Find all <span> elements that have the class "font-bold"
  • Loop through the elements and display the clean text names of the countries

Code

import requests
from bs4 import BeautifulSoup

url = "https://www.worldometers.info/geography/flags-of-the-world/"

result = requests.get(url)
data = result.content
soup = BeautifulSoup(data , "html.parser")

# Find country names using class filter
country_names = soup.find_all("span", class_="font-bold")
for country in country_names:
    print(country.text)

Activity 3: Downloading Country Flag Images

Scrape the flag page to extract both country names and image links, create individual folders for each country name, and download their respective flag image files into those folders.

Tasks Performed

  • Extract country text and matching image tags from the webpage
  • Create absolute image URLs by joining the base domain name
  • Use os.mkdir() to automatically generate a unique folder for each country
  • Download the image files in binary format ("wb") and save them locally

Code

import requests
from bs4 import BeautifulSoup
import os

url = "https://www.worldometers.info/geography/flags-of-the-world/"

result = requests.get(url)
data = result.content
soup = BeautifulSoup(data , "html.parser")

c_names = soup.find_all("span", class_="font-bold")
c_flags = soup.find_all("img")
c_flags.pop(0) # Remove logo header image

country_names = []
for i in c_names:
    country_names.append(i.text)

country_flags = []
for j in c_flags:
    country_flags.append(j.get("src"))

# Loop to create folders and save images
for country, flag in zip(country_names, country_flags):
    flag = "https://www.worldometers.info" + flag
    country = country.replace(" ", "") # Remove spaces for folder name

    path = os.path.join(os.getcwd(), country)
    if not os.path.exists(path):
        os.mkdir(path)

    img = requests.get(flag)
    img_path = os.path.join(path, country + ".webp")
    with open(img_path, "wb") as f:
        f.write(img.content)

Activity 4: Scraping Quotes and Authors

Target a quotes website to pull a list of famous sayings along with the respective authors who said them, storing the final pairs inside a list.

Tasks Performed

  • Locate quote text using "span" tags with class "text"
  • Locate author names using "small" tags with class "author"
  • Combine data points using zip() and organize them into an index array

Code

import requests
from bs4 import BeautifulSoup

url = "http://quotes.toscrape.com/"
data = requests.get(url).content
soup = BeautifulSoup(data, "html.parser")

quotes = soup.find_all("span", class_="text")
authors = soup.find_all("small", class_="author")

result = []
for quote, author in zip(quotes, authors):
    row = []
    row.append(quote.text)
    row.append(author.text)
    result.append(row)

print(result)

Activity 5: Job Portal Scraping (Fake Jobs Dataset)

Scrape a sample job portal website to gather four key elements: Job Title, Company Name, Location Address, and Date Posted. Save the gathered items inside structured dictionary logs.

Tasks Performed

  • Target specific HTML tags (h2, h3, p, time) with their matching styling classes
  • Clean text alignment values using the .strip() method
  • Map attributes clearly into Key-Value format dictionaries and print them

Code

import requests
from bs4 import BeautifulSoup

url = "https://realpython.github.io/fake-jobs/"
data = requests.get(url).content

soup = BeautifulSoup(data, "html.parser")

# Find elements by specific classes
job_title = soup.find_all("h2", class_="title is-5")
company_name = soup.find_all("h3", class_="subtitle is-6 company")
address = soup.find_all("p", class_="location")
date = soup.find_all("time")

result = []
for jt, cn, a, d in zip(job_title, company_name, address, date):
    row = {}
    row["job title"] = jt.text
    row["company name"] = cn.text
    row["address"] = a.text.strip() # Clear whitespaces
    row["date posted"] = d.text
    result.append(row)

# Print final job profiles
for i in result:
    print(i)
