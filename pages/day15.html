Activity 1: One-Hot Encoding Preprocessing & Data Pipeline Integration

Implement automated categorical feature detection and one-hot encoding on the insurance dataset before partitioning training and test splits.

Tasks Performed

  • Isolate continuous target outputs (charges) from predictor attributes
  • Detect qualitative categorical variables programmatically using string data type inspection
  • Apply OneHotEncoder(sparse_output=False) to transform discrete categories into binary sparse-dense matrices
  • Reconstruct the dataset matrix by concatenating transformed feature arrays with original continuous numerical columns

Code

import pandas as pd
import numpy as np
from sklearn.preprocessing import OneHotEncoder
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score
from sklearn.tree import DecisionTreeRegressor
from sklearn.svm import SVR
from sklearn.ensemble import RandomForestRegressor

# Load dataset
data = "insurance.csv"
df = pd.read_csv(data)

# Preprocessing: Separate target output variable
y = df["charges"]
df = df.drop(columns="charges")

# Dynamically select categorical columns and encode them
categorical_columns = df.select_dtypes(include=['str']).columns
encoder = OneHotEncoder(sparse_output=False)
encoded_data = encoder.fit_transform(df[categorical_columns])

# Create encoded DataFrame and merge with non-categorical features
encoded_df = pd.DataFrame(encoded_data, columns=encoder.get_feature_names_out(categorical_columns))
df = pd.concat([df.drop(columns=categorical_columns), encoded_df], axis=1)

# Randomly permutation shuffle indices
indices = np.random.permutation(len(df))

# Partition into 80% training and 20% testing splits
split_index = int(len(df) * 0.80)
x_train = df.iloc[:split_index]
y_train = y.iloc[:split_index]
x_test = df.iloc[split_index:]
y_test = y.iloc[split_index:]

Activity 2: Comparative Evaluation on Encoded Feature Matrix

Fit regression models on the preprocessed, fully encoded feature set and analyze output accuracy metrics across multiple algorithms.

Tasks Performed

  • Train Decision Tree Regressor, Support Vector Regressor (SVR), and Random Forest Regressor models
  • Predict customer insurance charges on unseen test feature matrices
  • Calculate MAE, MSE, RMSE, and $R^2$ scores across all fitted regression algorithms
  • Compare performance improvements gained by retaining categorical features via One-Hot Encoding

Code

# 1. Decision Tree Regressor
dtr = DecisionTreeRegressor().fit(x_train, y_train)
prediction = dtr.predict(x_test)
mae = mean_absolute_error(y_test, prediction)
mse = mean_squared_error(y_test, prediction)
rmse = np.sqrt(mse)
r2 = r2_score(y_test, prediction)

print("--- Decision Tree Regressor ---")
print("Mean Absolute Error     :", mae)
print("Mean Squared Error      :", mse)
print("Root Mean Squared Error :", rmse)
print("R2 Score                :", r2)

# 2. Support Vector Regressor
svr = SVR().fit(x_train, y_train)
prediction = svr.predict(x_test)
mae = mean_absolute_error(y_test, prediction)

rmse = np.sqrt(mse)

print("\n--- Support Vector Regressor ---")
