Day 17 - Deep Learning Essentials: Building Artificial Neural Networks (ANN) with Keras

Industrial Training Diary

Introduction

On the seventeenth day of industrial training, I transitioned into Deep Learning by constructing my first Artificial Neural Network (ANN) using Keras and TensorFlow. I built a Multi-Layer Perceptron (MLP) architecture to perform binary classification on the Pima Indians Diabetes dataset. The task involved loading raw numerical array data using NumPy, partitioning train-test splits, designing a dense neural network layout, configuring optimization parameters, and evaluating overall classification accuracy and loss performance.

Learning Objectives

  • Load comma-separated numerical datasets into NumPy matrices using loadtxt
  • Construct Sequential neural network architectures using TensorFlow Keras Dense layers
  • Understand non-linear activation functions including Rectified Linear Unit (ReLU) and Sigmoid
  • Configure neural network training using binary_crossentropy loss, Adam optimizer, and accuracy metrics
  • Train neural network models over fixed epochs and batch_size parameters, evaluating holdout performance

Activity 1: Dataset Partitioning & Neural Network Architecture Setup

Import numerical diagnostic features from the Pima Indians Diabetes dataset, split observations into feature and target matrices, and set up a reproducible train-test split.

Tasks Performed

  • Load comma-delimited numeric array data using NumPy's loadtxt function
  • Slice diagnostic feature variables ($X$, columns $0$ to $7$) from binary target labels ($y$, column $8$)
  • Apply Scikit-Learn's train_test_split with a 20% holdout test set and seed control (random_state=42)
  • Initialize Keras Sequential architecture with hidden dense layers utilizing ReLU activations

Code

from numpy import loadtxt
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense
from sklearn.model_selection import train_test_split

# Load dataset using NumPy
dataset = loadtxt("pima-indians-diabetes.csv", delimiter=",")

# Slice features (X) and target label (y)
x = dataset[:, 0:8]
y = dataset[:, 8]

# Partition into 80% training and 20% testing splits
x_train, x_test, y_train, y_test = train_test_split(
    x, y, test_size=0.20, random_state=42
)

# Initialize Sequential ANN Model Architecture
model = Sequential()
model.add(Dense(12, input_shape=(8,), activation='relu'))
model.add(Dense(8, activation='relu'))
model.add(Dense(1, activation='sigmoid'))

Activity 2: Model Compilation, Iterative Training & Test Set Evaluation

Compile the multi-layer neural network with appropriate loss functions, train across multiple training epochs, and evaluate overall loss and prediction accuracy on unseen test data.

Tasks Performed

  • Compile ANN model using binary_crossentropy loss function suited for binary classification tasks
  • Attach Adam adaptive learning rate optimizer and set tracking metric to accuracy
  • Fit model on training samples across $150$ epochs with a batch size of $10$
  • Evaluate model loss and accuracy performance on holdout test features using model.evaluate()

Code

# Compile model with loss function, optimizer, and metrics
model.compile(loss='binary_crossentropy', optimizer='adam', metrics=['accuracy'])

# Fit ANN model on training dataset
model.fit(x_train, y_train, epochs=150, batch_size=10)

# Evaluate performance metrics on holdout test set
loss, accuracy = model.evaluate(x_test, y_test)

# Display final test results
print("\n--- Model Evaluation Results ---")
print("Loss     : %.4f" % loss)
print("Accuracy : %.2f%%" % (accuracy * 100))

Key Learnings

  • Understanding the fundamentals of Artificial Neural Networks (ANN) and Multi-Layer Perceptrons (MLP)
  • Using Keras Sequential models to layer dense fully connected (Dense) network topologies
  • Applying ReLU activation functions for internal hidden layers to prevent vanishing gradient problems, and Sigmoid output activations for probability estimation
  • Understanding deep learning hyperparameters like epochs (full dataset iterations) and batch_size (samples per gradient update)
  • Configuring appropriate compilation parameters for binary outcome prediction using binary_crossentropy and adam
