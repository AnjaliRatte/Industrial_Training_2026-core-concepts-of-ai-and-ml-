Activity 1: Automated Window Scrolling and Extraction Pipeline (JioMart Large Appliances)

Automate a browser session targeting the JioMart store page, execute a mathematical increment sequence loop to dynamically scroll down the viewport to trigger content rendering, and harvest the loaded Product Titles and Prices.

Tasks Performed

  • Execute window scrolling operations utilizing the driver.execute_script() driver method
  • Establish mathematical loop parameters to progressively shift view ranges down by 500 pixels every 3 seconds
  • Extract clean dataset elements by targeting product card containers with BeautifulSoup
  • Use slice limits ([:100]) to structure the output matrix and print bounded item summaries

Code

from bs4 import BeautifulSoup
import time
from selenium import webdriver
from selenium.webdriver.chrome.service import Service
from webdriver_manager.chrome import ChromeDriverManager

# Initialize web driver components
service = Service(ChromeDriverManager().install())
driver = webdriver.Chrome(service=service)
url = "https://www.jiomart.com/sections/large-appliances"

driver.get(url)
time.sleep(20) # Safe buffer delay for complete core component initialization

# Initialize scrolling coordinate tracking variables
x = 0
y = 500
for i in range(5):
    # Dynamically scroll window perspective down the layout
    driver.execute_script("window.scrollTo(" + str(x) + ", " + str(y) + ");")
    x = y
    y = y + 500
    time.sleep(3) # Wait for newly scrolled elements to render onto DOM

soup = BeautifulSoup(driver.page_source, "html.parser")
title = soup.find_all("h3", class_="productCard__productTitle")
price = soup.find_all("span", class_="PriceContainer__currentPrice")
print(len(title), len(price))

result = []
# Match listings and slice down to target limit
for t, p in list(zip(title, price))[:100]:
    result.append([t.get_text(strip=True), p.get_text(strip=True)])

print(result)
print(len(result))
driver.quit()

Activity 2: Multi-Tier Product Catalog Harvesting (Ajio Caps & Hats Catalog)

Automate search results parsing for fashion accessories by mapping item lists, querying individual child links, and attempting to extract Product Names, Sale Prices, Brand Names, MRPs, and Description sections.

Tasks Performed

  • Locate product card wrappers using grid layout styling markers
  • Reconstruct item absolute links and save them inside tracking loops
  • Navigate deep child addresses using the same automated browser instance
  • Extract descriptive specifications (such as names, tags, and descriptive blocks) into data rows

Code

import time
from selenium import webdriver
from bs4 import BeautifulSoup
from selenium.webdriver.chrome.service import Service
from webdriver_manager.chrome import ChromeDriverManager

service = Service(ChromeDriverManager().install())
driver = webdriver.Chrome(service=service)

url = "https://www.ajio.com/s/caps-and-hats-4461-75481"
driver.get(url)
time.sleep(5)

soup = BeautifulSoup(driver.page_source, "html.parser")
products = soup.find_all("a", {"class": "rilrtl-products-list__link desktop"})

# Gather independent listing links
items = []
for p in products:
    items.append("https://www.ajio.com" + p.get("href"))

result = []
for item in items:
    driver.get(item)
    time.sleep(5) # Delay buffer to allow inner item values to safely load

    sp = BeautifulSoup(driver.page_source, "html.parser")

    # Extract details using descriptive class tags
    name = sp.find("h1", class_="prod-name").text
    sale_price = sp.find("div", class_="prod-sp").text
    brand = sp.find("h2", class_="brand-name").text
    mrp = sp.find("span", class_="prod-cp").text
    prod_details = sp.find("section", class_="prod-desc") # Captures description block element

    result.append([name, sale_price, brand, mrp, prod_details])

print(result)
driver.quit()
